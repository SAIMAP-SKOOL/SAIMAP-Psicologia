# SAIMAP Psicología

Aprende Psicología con lecciones cortas, repaso diario y rutas para el Grado y el PIR. Aplicación web progresiva (PWA) con el temario SAIMAP de cada asignatura, publicada en GitHub Pages y empaquetada para Android como Trusted Web Activity.

- Web: https://saimap-skool.github.io/SAIMAP-Psicologia/
- Rama `main`: la web publicada (raíz) y el proyecto Android (`android/twa`).
- Rama `fuente`: código de la app, contenido de los cursos y fuentes de los temarios.
- Rama `android-build`: AAB y APK sin firmar generados por GitHub Actions.

La clave de subida a Google Play no está en el repositorio.
